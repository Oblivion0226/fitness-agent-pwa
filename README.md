# 练得明白 · 健身 Agent PWA

本地优先测试版：个人档案、课表空档、训练记录、聊天历史和计划均写入浏览器 IndexedDB；每位测试者设备独立。

## 启动

在此目录运行：

```powershell
npx serve .
```

打开输出的本机地址。手机测试时需将静态文件部署到 HTTPS 静态托管；不要把 DeepSeek API Key 写进代码或提交到仓库。

## 当前边界

- API Key 只保留本次浏览器会话；关闭浏览器即清除。
- 纯前端直连 DeepSeek 是否可用取决于其浏览器跨域策略；若被拦截，后续再加一个无状态转发函数。
- 本地长期记忆不跨设备同步，用户清除浏览器数据会丢失；可通过“导出我的数据”备份。
